# 已封存功能

## 数字人（Digital Human）

状态：自 2026-10-03 起只读封存。

数字人功能曾包含 `digital_human` 表、`assessment.digital_human_id` 关联列以及后端媒体签名和响应 DTO，但没有形成可用的前端选择、管理或播放闭环。为避免未完成能力继续影响考核列表、待考核列表和考核详情，运行时代码已经移除。

封存边界如下：

- 已发布的 Flyway V1 不得改写。
- `digital_human` 表和 `assessment.digital_human_id` 列继续保留，用于兼容已有数据库和历史数据。
- 这两个数据库对象属于只读封存数据：当前应用不得写入、更新或删除其中的数据。
- 当前应用不查询、不传输 `digital_human` 数据，不映射 `assessment.digital_human_id`，也不通过 REST、WebSocket 或前端页面传输数字人、视频或口型数据。
- 当前应用不再为数字人媒体生成 OSS 签名地址，也不存在数字人的 Controller、Mapper、Service 或前端入口。
- 运维升级和日常数据清理不得顺带删除表、列或历史值。

如未来重新启用，必须作为新功能重新设计并通过新的前向数据库迁移交付；至少需要明确的数据迁移、唯一默认项约束、对象所有权、管理 API、教师选择界面、学生播放能力和端到端测试。在这些条件完成前，不得通过恢复旧 Java 类型或直接读取封存列的方式重新接入。

若未来决定永久删除，必须先在目标环境统计 `digital_human` 数据、非空 `assessment.digital_human_id`、悬空引用和备份可恢复性，再通过单独的前向迁移执行；禁止修改 V1 或手工直接 drop 表/列。

## 项目类型（Project Type）

状态：自 2026-10-03 起只读封存。

历史 `project_type` 表没有被任何考核、记录或用户关系引用，前端筛选入口也已长期隐藏。为避免继续维护一套没有业务闭环的 CRUD 接口，当前应用已移除对应的 Controller、应用服务、Mapper、持久化对象和前端请求封装。

- 已发布的 Flyway V1 及其中的 `project_type` 表继续保留，不得改写。
- 当前应用不读写该表，也不提供 `/project-type/**` HTTP 接口。
- 若未来恢复，必须先明确它与考核设置的真实关系，并通过新的前向迁移、正式产品入口、权限策略和端到端测试重新交付。
- 若未来永久删除，必须先核查目标环境数据和备份可恢复性，再使用单独的前向迁移删除。
